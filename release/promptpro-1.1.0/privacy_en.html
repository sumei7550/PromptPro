Privacy Policy

Last updated: 2026-08-03

1. Data Collection

PromptPro does not collect any personal information, user input, browsing history, or other sensitive data.

2. Data Usage

Prompt optimization and template processing run locally in the user's browser by default. PromptPro does not upload prompt content, sell it, or use it to train models.

3. Permissions

  • storage: Used only to save local data such as language preference, UI settings, custom templates, and the daily free-quota counter on the user's device.
  • activeTab: Used only when the user actively clicks the PromptPro floating button or the "Insert Template" button to read/write text in the input field of the current AI platform page.
  • scripting: Used only when the user clicks "Insert Template" on a page where the content script is not yet attached, to inject a one-shot input-writing function.
  • host_permissions: Used only to mount the floating button on supported AI pages, including ChatGPT, Claude, Gemini, DeepSeek, Doubao, Perplexity, Copilot, Grok, Google AI Studio, Cursor, v0, and Lovable. The extension never auto-navigates or sends messages on the user's behalf.

4. Third-party Services

This extension does not use any third-party analytics, tracking, or advertising services, and does not upload user input or browsing data to any remote server. All prompt-optimization logic runs locally in the user's browser.
