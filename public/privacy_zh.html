隐私政策

最后更新日期：2026-09-05

1. 数据处理

当用户主动使用 PromptPro 时，扩展会读取支持的 AI 页面输入框中的文本，用于提示词优化或模板插入。用户主动输入的内容可能包含个人信息、网页内容、表单数据、个人通信或其他用户生成内容。

使用 AI 优化时，PromptPro 仅将当前提示词文本及最少的优化设置（语言、风格和目标平台）发送到 PromptPro API，再由该 API 转发给 DeepSeek 处理。不会发送页面 DOM、Cookie、完整对话历史、已保存提示词、优化历史或无关页面内容。PromptPro 不会被动记录浏览历史。

2. 数据使用

AI 提示词优化按上述方式远程处理；发生网络、超时或服务异常时，PromptPro 可能使用扩展内置的本地规则回退。模板搜索和变量替换仍在本地完成。用户接受优化结果后，原始提示词和优化结果可能作为优化历史保存在本地 Chrome 存储中，同时保存自定义模板、设置、语言偏好和使用次数。优化历史最多保留最近 50 条，用户可以通过清除扩展本地数据删除。

3. 权限说明

  • storage：用于保存本地设置、模板、优化历史、使用次数，以及从 Chrome Sync 存储迁移旧设置。迁移完成后，PromptPro 不会持续使用 Sync 存储。
  • scripting：仅在用户点击“插入模板”且内容脚本不可用时，在当前支持的 AI 页面注入一次性的输入框写入函数。
  • contextMenus：用于提供“将选中文本保存为模板”的右键菜单项。
  • host_permissions：用于在列出的支持 AI 页面上运行功能，并将用户主动发起的优化请求发送到 prompt-pro-psi.vercel.app 的 PromptPro API。扩展不会获得 Provider API Key，也不会代替用户自动提交消息。

4. 第三方服务

本扩展仅在用户主动发起 AI 优化时使用 PromptPro API 和 DeepSeek 处理该请求。服务端实现不会主动将提示词正文持久化到应用数据库，也不会将正文写入应用日志；DeepSeek 会依据其适用条款和数据处理规则处理请求。本扩展不包含分析、追踪或广告服务。

5. Chrome Web Store 用户数据政策

数据仅用于提供 PromptPro 面向用户的功能：AI 提示词优化、本地回退、模板管理和用户主动请求的内容插入。PromptPro 不出售提示词内容，也不将其用于广告。AI 优化会按上述说明将当前提示词和最少请求设置传输给 PromptPro API 与 DeepSeek。
