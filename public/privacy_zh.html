隐私政策

最后更新日期：2026-08-04

1. 数据处理

当用户主动使用 PromptPro 时，扩展会读取支持的 AI 页面输入框中的文本，用于提示词优化或模板插入。用户主动输入的内容可能包含个人信息、网页内容、表单数据、个人通信或其他用户生成内容。

PromptPro 在浏览器本地处理这些内容，不会收集、上传、出售、共享提示词内容，也不会将其用于广告或模型训练。PromptPro 不会被动记录浏览历史，也不会读取与输入框无关的页面内容。

2. 数据使用

所有提示词优化和模板处理均在用户浏览器本地运行。原始提示词和优化结果可能作为优化历史保存在本地 Chrome 存储中，同时保存自定义模板、设置、语言偏好和使用次数。优化历史最多保留最近 50 条，用户可以通过清除扩展本地数据删除。

3. 权限说明

  • storage：用于保存本地设置、模板、优化历史、使用次数，以及从 Chrome Sync 存储迁移旧设置。迁移完成后，PromptPro 不会持续使用 Sync 存储。
  • scripting：仅在用户点击“插入模板”且内容脚本不可用时，在当前支持的 AI 页面注入一次性的输入框写入函数。
  • contextMenus：用于提供“将选中文本保存为模板”的右键菜单项。
  • host_permissions：仅在列出的支持 AI 页面上挂载浮动按钮和处理输入框，不会自动跳转或代为发送消息。

4. 第三方服务

本扩展不使用第三方分析、追踪或广告服务，不向远程服务器上传用户输入或浏览数据。提示词优化逻辑全部在用户浏览器本地完成。

5. Chrome Web Store 用户数据政策

PromptPro 对从 Chrome 和受支持网页获得的信息的使用符合 Chrome Web Store 用户数据政策及 Limited Use（有限使用）要求。数据仅用于实现扩展的单一用途：本地提示词优化、模板管理和用户主动请求的内容插入。PromptPro 不出售数据、不将数据用于广告、不向第三方传输数据，也不允许人工查看用户内容。
