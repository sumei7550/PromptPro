Privacy Policy

Last updated: 2026-08-04

1. Data Handling

When you actively use PromptPro, the extension reads the text in the supported AI page's input field to provide prompt optimization or template insertion. This may include personal information, website content, form data, personal communications, or other user-generated content that you choose to enter.

PromptPro processes this content locally in your browser. It does not collect, upload, sell, share, or use your prompt content for advertising or model training. PromptPro does not passively record browsing history or read page content unrelated to the input field.

2. Data Usage

Prompt optimization and template processing run locally in the user's browser. The original prompt and optimized result may be saved in local Chrome storage as optimization history, together with custom templates, settings, language preference, and usage counters. The history is limited to the most recent 50 entries and can be removed by clearing the extension's local data.

3. Permissions

  • storage: Used for local settings, templates, optimization history, usage counters, and migration of legacy settings from Chrome Sync storage. PromptPro does not use Sync storage for ongoing storage.
  • scripting: Used only after the user clicks "Insert Template" when the content script is unavailable, to inject a one-time input-writing function on the active supported page.
  • contextMenus: Used to provide the menu item that saves user-selected text as a local template draft.
  • host_permissions: Used only to mount the floating button on supported AI pages, including ChatGPT, Claude, Gemini, DeepSeek, Doubao, Perplexity, Copilot, Grok, Google AI Studio, Cursor, v0, and Lovable. The extension never auto-navigates or sends messages on the user's behalf.

4. Third-party Services

This extension does not use any third-party analytics, tracking, or advertising services, and does not upload user input or browsing data to any remote server. All prompt-optimization logic runs locally in the user's browser.

5. Chrome Web Store User Data Policy

PromptPro's use of information received from Chrome and supported webpages complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide the extension's single purpose: local prompt optimization, template management, and user-requested insertion. PromptPro does not sell, use for advertising, or transfer this data to third parties, and does not allow human review of user content.
