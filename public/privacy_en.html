Privacy Policy

Last updated: 2026-09-05

1. Data Handling

When you actively use PromptPro, the extension reads the text in the supported AI page's input field to provide prompt optimization or template insertion. This may include personal information, website content, form data, personal communications, or other user-generated content that you choose to enter.

For AI optimization, PromptPro sends only the current prompt text and the minimum optimization settings (language, style, and target platform) to the PromptPro API, which forwards the request to DeepSeek for processing. It does not send the page DOM, cookies, conversation history, saved prompts, optimization history, or unrelated page content. PromptPro does not passively record browsing history.

2. Data Usage

AI prompt optimization is processed remotely as described above. If that service has a network, timeout, or service failure, PromptPro may use its bundled local-rule fallback. Template search and variable replacement remain local. After a user accepts an optimization, the original prompt and optimized result may be saved in local Chrome storage as optimization history, together with custom templates, settings, language preference, and usage counters. The history is limited to the most recent 50 entries and can be removed by clearing the extension's local data.

3. Permissions

  • storage: Used for local settings, templates, optimization history, usage counters, and migration of legacy settings from Chrome Sync storage. PromptPro does not use Sync storage for ongoing storage.
  • scripting: Used only after the user clicks "Insert Template" when the content script is unavailable, to inject a one-time input-writing function on the active supported page.
  • contextMenus: Used to provide the menu item that saves user-selected text as a local template draft.
  • host_permissions: Used to operate on the listed supported AI pages and to send user-requested optimization calls to the PromptPro API at prompt-pro-psi.vercel.app. The extension does not receive the provider API key and does not automatically submit messages on the user's behalf.

4. Third-party Services

The extension uses the PromptPro API and DeepSeek only to process AI optimization requests initiated by the user. The server implementation does not intentionally persist prompt bodies in an application database or include them in application logs. DeepSeek processes these requests under its own applicable terms and data practices. The extension does not include analytics, tracking, or advertising services.

5. Chrome Web Store User Data Policy

Data is used only to provide PromptPro's user-facing purposes: AI prompt optimization, the local fallback, template management, and user-requested insertion. PromptPro does not sell prompt content or use it for advertising. AI optimization necessarily transfers the current prompt and minimum request settings to the PromptPro API and DeepSeek as described above.
