# PromptPro 1.1.0 Chrome Web Store listing

## Recommended listing copy

### Title

PromptPro: Local Prompt Optimizer

### Short description

Improve prompts locally and reuse 66 bilingual templates across AI websites.

### Detailed description

Write clearer prompts. Get more useful AI responses.

PromptPro is a local-first Chrome extension that helps you improve prompts before sending them and reuse proven templates across the AI tools you already use. Prompt text is processed locally in the browser.

KEY FEATURES

• One-click prompt enhancement directly on supported AI chat pages
• Fully local optimization logic with no account and no prompt uploads
• 66 ready-to-use bilingual templates for writing, coding, marketing, research, analysis and creative work
• Search templates by task, keyword or category
• Insert templates into ChatGPT, Claude, Gemini, DeepSeek, Doubao, Perplexity and other supported AI platforms
• Custom templates, variables, optimization history and undo
• English and Simplified Chinese UI

SUPPORTED AI PLATFORMS

ChatGPT, Claude, Gemini, DeepSeek, Doubao, Perplexity, Copilot, Grok, Google AI Studio, Cursor, v0 and Lovable.

PRIVACY FIRST

PromptPro does not require an account. When you use an optimization or insertion feature, the extension reads the relevant input or selected text and processes it locally. Your prompts, templates, settings and history stay in Chrome storage on your device. The extension does not use analytics, advertising, remote prompt processing, or automatic message submission.

HOW IT WORKS

1. Open a supported AI chat page.
2. Type a rough idea or choose a template from the extension popup.
3. Click Optimize or Insert Template.
4. Review the result, adjust it if needed, and send it yourself.

PromptPro never automatically submits messages on your behalf.

### Permission and data-use disclosure

- `storage`: Saves settings, custom templates, optimization history and usage counters locally. A legacy setting may be read from Chrome Sync once for migration; ongoing storage uses local Chrome storage.
- `scripting`: Used only after the user clicks Insert Template, as a one-time fallback to write the selected template into a supported page's input.
- `contextMenus`: Lets the user save explicitly selected text as a local template draft.
- Host permissions: Restrict the content script and input handling to the supported AI sites listed above. The extension does not read unrelated page content, navigate automatically, or submit messages.

PromptPro's use of user data complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. User data is used only to provide the extension's single purpose, is not sold or used for advertising, and is not transferred to third parties.
