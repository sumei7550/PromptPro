# 阶段一验收记录

日期：2026-08-03

## 已完成

- 增加优化前后预览弹窗。
- 用户取消时保留原始 Prompt，不扣除每日额度。
- 用户确认后才写入优化结果并扣除一次额度。
- 增加优化完成后的撤销操作。
- 优化失败时显示错误状态，原文不被静默替换。
- Content Script 启动时读取用户语言设置，预览和 Toast 支持中英文。
- 设置优先存储在 `chrome.storage.local`，兼容迁移旧的 `chrome.storage.sync` 设置。
- 更新中英文隐私政策，明确 Prompt 默认不上传、不出售、不用于模型训练。

## 手工验收清单

在 Chrome 重新加载扩展后，分别于 ChatGPT、Claude、DeepSeek 验证：

- [ ] 输入 Prompt，点击浮动按钮，能看到原文和优化后内容。
- [ ] 点击“保留原文”，输入框内容不变，额度不减少。
- [ ] 点击“使用优化结果”，输入框替换为优化结果，额度减少 1 次。
- [ ] 点击“撤销”，输入框恢复原文。
- [ ] 将额度用完后，点击优化不会修改输入框。
- [ ] 切换中文/英文后，预览、Toast 和设置文案语言一致。
- [ ] 打开隐私政策，内容与本地运行行为一致。
