# PromptPro 产品迭代路线

> 版本：2026-08-03
> 原则：每个阶段独立交付、独立验收；未通过当前阶段验收，不进入下一阶段。

## 总目标

把 PromptPro 从“本地提示词改写器 + 静态模板库”升级为“隐私优先的 AI 任务工作流助手”。

核心产品闭环：

```text
选择任务 → 填写少量关键信息 → 生成可执行 Prompt → 注入 AI 平台
       → 查看优化前后差异 → 保存成功版本 → 下次一键复用
```

## 阶段一：产品承诺与核心体验对齐

### 目标

让商店承诺、产品文案和实际代码一致，先解决信任、可理解性和首次使用体验问题。

### 工作范围

- 明确“本地规则优化”和“可选 AI 优化”的产品边界。
- 统一 README、PRD、隐私说明、扩展设置页和商店文案。
- 优化按钮增加原始文本保护、优化前后预览和撤销能力。
- 增加优化风格：简洁、专业、结构化、深度分析、内容创作、代码。
- 明确错误状态、额度状态和当前优化方式。
- 修复设置存储、每日额度、双语文案和实际实现之间的不一致。
- 记录必要的本地使用状态，但默认不采集 Prompt 内容。

### 不在本阶段

- 不接入新的模型 API。
- 不做账号、支付和云端同步。
- 不做社区模板和团队空间。
- 不大规模增加模板数量。

### 验收标准

- 用户可以看到优化前后内容，并能撤销。
- 优化失败不会静默替换内容。
- 用户能明确知道本次是本地规则优化还是模型优化。
- 中英文界面、设置和隐私说明不再出现乱码或相互矛盾。
- `npm run build` 通过。
- 至少覆盖 ChatGPT、Claude、DeepSeek 三个平台的手工验收。

### 阶段交付物

- 核心体验代码和测试结果。
- 更新后的产品说明和隐私说明。
- 商店详情页改版文案与截图脚本。
- 阶段验收记录。

## 阶段二：任务表单与结果导向优化

### 目标

把“泛化提示词改写”变成“按任务生成可执行 Prompt”。

### 工作范围

- 任务入口：写作、职场、编程、分析、翻译、营销、学习。
- 变量表单：目标、背景、受众、语气、输出格式、限制条件。
- 从模板自动提取变量并生成表单。
- 生成前允许用户检查和修改变量。
- 优化后提供复制、替换、撤销三个动作。
- 支持模板变量缺失时的自然补问或跳过。

### 验收标准

- 用户完成一次常见任务不超过 30 秒。
- 至少 10 个高频任务具备变量表单。
- 生成结果不会丢失用户原始意图。
- 表单在中英文环境下均可使用。
- 现有一键优化流程仍然可用。

## 阶段三：个人 Prompt 资产

### 目标

让用户积累自己的可复用工作资产，形成留存和未来付费基础。

### 工作范围

- 自定义模板。
- 收藏、最近使用和搜索。
- 优化历史与版本对比。
- 一键复制、插入和重复使用。
- JSON/Markdown 导入导出。
- 快捷键和右键菜单。

### 验收标准

- 用户可以在 3 次操作内保存一个模板并再次复用。
- 历史记录不会泄露到网络。
- 导入导出数据可逆。
- 扩展重启后数据仍然存在。

## 阶段四：平台覆盖与增长基础

### 目标

扩大使用场景，同时建立质量反馈和商店转化基础。

### 工作范围

- 增加 Perplexity、Copilot、Grok、Google AI Studio、Cursor、v0、Lovable 等平台评估。
- 平台适配器健康检查和版本回归测试。
- 本地匿名统计：安装激活、优化成功率、模板使用、卸载前反馈；默认不采集 Prompt 内容。
- 商店截图、演示视频、FAQ 和隐私说明改版。
- 建立崩溃和适配失败反馈入口。

### 验收标准

- 新增平台逐个通过输入、插入、替换、撤销测试。
- 关键行为有可关闭的匿名统计说明。
- 商店首屏能在 10 秒内表达产品价值。
- 能区分“功能问题”和“用户不需要”。

## 阶段五：商业化验证

### 目标

在核心留存成立后，再验证个人 Pro 和团队版收入。

### 个人 Pro

- 无限优化。
- 无限自定义模板。
- 历史和版本管理。
- 高级任务表单。
- 更多平台和快捷操作。

### Team

- 团队模板库。
- 权限和共享。
- 品牌语气与写作规范。
- 使用统计。
- 私有空间。

### 建议价格

- Pro：¥19–29/月，¥199–299/年。
- Team：早期按 5–10 人小团队定价，先做人工销售验证。
- BYOK：允许用户使用自己的模型 API，降低服务端模型成本和隐私顾虑。

### 商业化前置条件

- 7 日留存达到可接受水平。
- 用户每周至少复用一次个人模板。
- 用户能明确感知高级功能带来的时间节省。
- 付费限制不会破坏首次价值体验。

## 阶段闸门

每个阶段结束时必须回答四个问题：

1. 用户是否能明显感受到价值？
2. 关键流程是否稳定？
3. 是否形成下一阶段的真实需求？
4. 是否有数据或手工反馈支持继续投入？

如果答案中有两个以上是否定，暂停新增功能，先修复当前阶段。
