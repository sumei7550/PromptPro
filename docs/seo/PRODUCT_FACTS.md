## 使用范围与证据等级

本文档是官网 MVP 和后续 Chrome 实测的事实基线。代码中存在的配置或 UI 入口，只能证明“已实现/已配置”，不能单独证明某个平台当前版本已经通过真实 Chrome 验证。

- **代码确认**：由当前仓库源码、Manifest 或静态隐私页直接确认。

- **待实测**：本轮没有启动真实 Chrome，也没有把配置的支持站点标记为已验证。

仓库已存在独立的 Next.js 官网工程，位于 `website/`，当前已完成 Homepage、Website IA v2、Header/Footer v2 和基础语言切换实现。Features、Privacy、Platforms、Templates 仍需完成正式正文，Pricing、FAQ、Support、About、Terms、Changelog 仍属于规划页面；官网 SEO Implementation 和 Release QA 尚未完成。可复用的扩展产品素材位于 `store-assets/`，扩展隐私静态页面位于 `public/privacy_en.html` 和 `public/privacy_zh.html`。

## D. 已实现的用户可见能力

以下能力有当前源码入口或数据实现支持：

- 在支持页面显示浮动按钮；读取当前输入框内容并触发本地提示词优化。
- 优化结果先进入预览/确认流程，用户可以取消或应用结果。
- 应用结果写回当前 AI 网站输入框；成功后提供一次“撤销”操作恢复原提示词。
- 本地规则优化和多种优化风格：简洁、专业、结构化、深度分析、内容创作、代码。
- 内置 8 个模板分类：写作、职场、编程、翻译、营销、学术、分析、创意。
- 仓库文案和 locale 声明为 66 个中英双语模板；官网发布前仍应以实际模板数组计数和 Chrome 实测为准。
- Popup 中按分类浏览模板，并支持基于中英文标题、关键词、描述、标签和分类的搜索。
- 模板插入当前支持页面输入框，也支持复制模板文本。
- 自定义模板、模板变量填写、个人模板版本历史/对比入口。
- 优化历史记录入口；代码将最近 50 条优化记录写入本地存储。
- 中英文界面切换；用户设置和语言偏好持久化。
- 右键菜单将用户主动选中的文本保存为本地模板草稿。
- 首次使用引导、使用次数显示和优化风格设置。

## E. 隐私、数据和权限事实

代码与现有隐私页支持以下表述：

- 不要求账号；仓库未发现后端服务、分析、广告或遥测实现。
- 优化逻辑在浏览器本地运行；本轮源码搜索未发现 `fetch` 或 `XMLHttpRequest` 远程调用。
- 提示词、模板、设置、历史和使用次数使用 `chrome.storage.local` 保存。
- `src/shared/storage.ts` 会读取旧的 `chrome.storage.sync` 设置用于迁移；持续存储使用 local。官网应如实说明这一迁移行为，不要声称从未访问过 Sync storage。
- 不自动导航、不代用户提交/发送消息；优化和模板插入均由用户操作触发。
- `storage`：保存本地设置、模板、历史和使用次数。
- `scripting`：模板插入时，内容脚本不可用的情况下执行一次性写入回退。
- `contextMenus`：提供保存用户选中文本为模板草稿的右键菜单。
- 主机权限：仅列出 Manifest 中的 AI/开发工具站点，不使用 `<all_urls>`。
